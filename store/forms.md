# Ответы для анкет RuStore

Готовый текст для консоли RuStore. Каждый ответ — утверждение о коде или о решении из
документов; поменялось одно — поменять другое в том же коммите. Где справку RuStore
сверить не удалось (сайт RuStore недоступен из среды ассистента), стоит **[проверить]**.

## Приложение

| Поле | Ответ | Откуда |
|------|-------|--------|
| Тип | Игра | — |
| Категория | Головоломки; если консоль предложит раздел для раскрасок — его | `listing.ru.md` |
| Имя пакета | `games.gornitsa.uzory` — постоянное с первой сборки | ADR 0014 |
| Подпись | постоянный ключ студии для «Узоров»; отпечаток — переменная `ANDROID_CERT_SHA256` | ADR 0014, `docs/05-process.md` |
| Файл | `uzory-N.apk` из Releases; две архитектуры (`arm64-v8a`, `armeabi-v7a`) | `.github/workflows/android.yml` |
| Возрастная категория (436-ФЗ) | **0+**: ни рекламы, ни чата, ни пользовательского контента; картинки отобраны без наготы, насилия и страшного | `docs/10-money.md`, «Возрастная категория» |
| Реклама | **нет** — ни в каком виде | ADR 0008 |
| Покупки | подписка «Узоры+» через RuStore Pay (месяц и год); других покупок нет | `docs/10-money.md` |

Подписка появляется в 0.3; до неё в анкете «Покупки» — «нет», и карточка меняется вместе
с версией, где подписка есть **[проверить: как RuStore отмечает, что покупки появятся]**.

## Разрешения APK

`INTERNET` и `ACCESS_NETWORK_STATE` — каталог и новые картинки; `VIBRATE` — отклик стежка;
`MODIFY_AUDIO_SETTINGS` — музыка (с 0.2). Остальное вырезано и проверяется в CI:
рекламный идентификатор, файлы, камера, микрофон, местоположение, контакты, показ поверх
окон, фоновая работа.

## Данные (если консоль спросит)

| Вопрос | Ответ | Почему |
|--------|-------|--------|
| Собирает ли приложение персональные данные? | **Нет** | работы и настройки не покидают телефон; запрос каталога не несёт ни номера установки, ни идентификаторов (ADR 0012) |
| Передаёт ли третьим лицам? | **Нет** | — |
| Подписка | обрабатывает RuStore; игра получает только «есть ли подписка и до какого числа» | `docs/10-money.md`, «152-ФЗ» |
| Отчёт об ошибке | игрок отправляет сам, письмом или через «Поделиться»; сама игра ничего не отправляет | `docs/specs/2026-09-first-picture.md` |
| Счётчики | суммы по обезличенным параметрам запроса каталога: версия, магазин, неделя установки, корзины дней, подписка да/нет, корзины картинок и минут | `docs/03-server-api.md`, «Счётчики» |

Политика конфиденциальности — раздел «Узоры» общей политики студии:
`https://gornitsa.games/privacy.html#uzory`. Текст раздела — [`site/privacy-uzory.ru.html`](site/privacy-uzory.ru.html);
**выложить на сайт до подачи карточки**.

## Права на картинки

Если модерация спросит, откуда картинки: работы в общественном достоянии (у каждой в карточке
сборки — источник и основание), снимки Прокудина-Горского из Библиотеки Конгресса США
(«без известных ограничений на публикацию»), орнаменты и снимки студии. Картинок из
генераторов изображений нет. Картины из российских музеев в выпуск идут только после
решения владельца (`docs/09-content.md`, §2, В12). Перечень источников — в игре,
«Настройки» → «О программе».

## Контакт разработчика

Разработчик — студия **«Горница»**. Почта поддержки для «Узоров» — ящик на домене
gornitsa.games у российского почтового сервиса (`docs/07-roadmap.md`, В11): письма
«Сообщить об ошибке» — персональные данные, их первичная запись — в России
(`docs/10-money.md`, «152-ФЗ»). Пока ящика нет, карточку на модерацию не подавать.
