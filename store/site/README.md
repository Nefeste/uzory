# Страница «Узоров» на gornitsa.games

[`page.ru.md`](page.ru.md) и [`page.en.md`](page.en.md) — страница игры на сайте студии и её
карточка на главной: поля и текст по формату устава студии (`Nefeste/gornitsa`,
`docs/08-publishing.md`, раздел «Сайт»; ADR студии 0015). Картинки — из `../graphics/` и
`../screenshots/ru/`, те же, что в карточке RuStore; WebP нужных размеров сайт делает сам.
Обложка страницы (`cover`, 3 : 1, без надписей) — `../graphics/cover.png`, её рисует
`bun tools/store/graphics.ts`.
Сайт забирает эту папку с `main` раз в сутки и открывает PR в свой репозиторий — сливает
владелец. Формат проверяет `tools/test/site.test.ts`.

Меняется видимое игроку — снимки, возможности, цена, статус, ссылка на предзаказ, — в том же PR
правится и `page.*.md`. Когда карточка RuStore пройдёт модерацию, ссылку «Предзаказ в RuStore»
вписать в поле `links` обеих страниц (кнопка под названием) и в `card.links` (карточка на главной).

[`privacy-uzory.ru.html`](privacy-uzory.ru.html) — черновик раздела «Узоры» в политике
конфиденциальности студии (`#uzory` в `src/privacy.html` репозитория сайта). Раздел живёт только
на сайте: переносится туда до подачи карточки в RuStore, после чего черновик удаляется (устав,
`docs/07-privacy.md`). Сайт этот файл не читает.

Строки nginx для раздачи наборов (`/uzory/v1/…`) — отдельная правка сайта, этап 0.4
(`docs/specs/2026-09-packs.md`).
