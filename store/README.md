# Магазин и сайт

Всё, что нужно карточке «Узоров» в RuStore — для предзаказа и потом для выхода, — и те же
материалы для страницы игры на gornitsa.games. Графика и снимки не рисуются руками: их
пересоздают скрипты из кода игры, поэтому они всегда показывают то, что игра рисует на самом деле.

| Файл | Что | Как обновить |
|---|---|---|
| [`preorder.md`](preorder.md) | план предзаказа в RuStore: что нужно, кто делает, порядок | руками |
| [`listing.ru.md`](listing.ru.md), [`listing.en.md`](listing.en.md) | название, краткое и полное описание, ключевые слова | руками; длины, чужие названия и обещания по выпуску (коллекции без картинок с «да» и музыка без «да» на пьесы — не называются) сверяет `tools/test/store.test.ts` |
| [`faq.ru.md`](faq.ru.md) | частые вопросы для карточки RuStore (к выходу 1.0) | руками |
| [`forms.md`](forms.md) | ответы для анкет RuStore: возраст, данные, покупки, права на картинки | руками, вместе с кодом |
| [`closed-test.md`](closed-test.md) | памятка тестировщику закрытого теста: как поставить, что попробовать, как прислать отчёт | руками, когда меняется то, о чём в ней сказано |
| `graphics/icon-512.png` | иконка 512 × 512 | `bun tools/store/icons.ts` |
| `graphics/feature-ru.png`, `feature-en.png` | баннер 1024 × 500 | `bun tools/store/graphics.ts` |
| `graphics/cover.png` | обложка страницы игры на сайте студии, 2400 × 800 (3 : 1), без надписей: рушник из своих орнаментов, последний мотив вышит наполовину — видны номера | `bun tools/store/graphics.ts` |
| `screenshots/ru/*.png` | шесть снимков экрана телефона 1080 × 1920 — кадры спецификации 1.0 | `bun tools/content/build.ts --release && npm run export:web && bun tools/store/shots.ts`, потом `bun tools/content/build.ts` (сценарию нужен набор для проверки) |
| [`site/`](site/) | страница игры на gornitsa.games и карточка на главной (`page.ru.md`, `page.en.md` — формат устава студии, ADR студии 0015; картинки — те же, что выше, WebP сайт делает сам), черновик раздела политики | вручную, [`site/README.md`](site/README.md); формат проверяет `tools/test/site.test.ts` |

**На снимках и баннере — только то, что можно выпускать**: картинки с «да» владельца и правами.
Снимки делаются с веб-сборки со встроенным набором выпуска (`--release`); со сборкой для проверки,
где есть и картинки без «да», скрипт снимать отказывается, а каталога по сети в кадре нет. Картин из
российских музеев нет, пока не решён В12 (`docs/09-content.md`, §2).

Кадры — шесть, как в спецификации 1.0 (`docs/specs/2026-09-v1.md`, «Карточка RuStore»), с 11.10.2026:
вышивание крупно («Крестьянские девушки» Прокудина-Горского), большая работа издалека, «Готово»
в рамке, библиотека и календарь игрока четвёртой недели (часы браузера — 24 октября 2026 года, вышиты
почти все картинки дня с 1 октября), «О картине» у «Красного заката» из Метрополитен-музея. Прежние
кадры «Крупные номера», «Мозаика» и «Как вышивалось» ушли: в спецификации их нет.
