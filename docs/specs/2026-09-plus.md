# Подписка «Узоры+»

**Версия:** 0.3 **Состояние:** делается — в 0.6.0 «Перенос» работ файлом; в 0.12.0 экран «Узоры+», права и запирание без покупки; экран с магазином и строку на «Готово» сценарий проходит с заглушкой RuStore Pay (15.10.2026); покупка через RuStore Pay — в коде (20.10.2026), включается переменной `RUSTORE_APP_ID`; критерий 2 — проверка на телефоне в тестовом режиме

## Зачем

«Узоры» должны зарабатывать с первого дня, а рекламы в них нет (ADR [0008](../adr/0008-no-ads.md)).
Единственный источник денег — подписка «Узоры+» через RuStore Pay. Она должна быть
**честной** настолько, чтобы об этом можно было написать в карточке магазина: цена
крупно, без пробных периодов с автосписанием, отмена понятна, начатое остаётся
(ADR [0009](../adr/0009-honest-subscription.md)). Этот этап запирает библиотеку по правилам
`access`, добавляет экран подписки, покупку, восстановление и перенос работ файлом.

## Что увидит игрок

Что даёт подписка, цены и где её предлагают — [`../08-game-design.md`](../08-game-design.md),
«„Узоры+“ глазами игрока». Здесь — поведение экранов.

### Экран «Узоры+»

```
┌──────────────────────────────────────┐
│ ←                          Узоры+    │
│                                      │
│  Вся библиотека — 300 картинок       │
│  и около десяти новых каждую неделю  │
│  [ряд превью из разных коллекций]    │
│                                      │
│  ○ 199 ₽ в месяц                     │
│  ● 990 ₽ в год  (≈ 83 ₽ в месяц)     │
│  [        Оформить за 990 ₽       ]  │
│                                      │
│  Подписка продлевается сама, пока    │
│  вы её не отмените. Отменить —       │
│  в RuStore: <раздел подписок>.       │
│  Картинки, начатые с подпиской,      │
│  можно дошить и после её окончания.  │
│                                      │
│  Восстановить покупки · Условия ·    │
│  Политика конфиденциальности         │
└──────────────────────────────────────┘
```

- Число картинок берётся из библиотеки, а не пишется в текст.
- Цены берутся из RuStore Pay (с валютой и форматом магазина); если RuStore не ответил —
  строки цен заменяет «Не удалось узнать цену. Попробуйте позже», кнопка неактивна.
- С подпиской экран показывает: «Узоры+ действует до 12 ноября», «Управлять подпиской» —
  открывает раздел подписок RuStore.
- Путь к отмене — «RuStore → Подписки → Отменить» (по справке RuStore); в текст экрана
  он попадает после сверки с приложением RuStore перед выпуском. Изменился — правится
  текст, а не оставляется старый.
- До кнопки — всё, что требует закон ([`../10-money.md`](../10-money.md), «Подписка и закон»):
  цена за период, срок, слово «автопродление», что деньги спишутся сразу и когда
  следующее списание, где отменить. Заранее отмеченных галочек нет. Кнопка «Закрыть»
  видна всегда.

### Покупка

1. «Оформить» → окно оплаты RuStore Pay поверх игры.
2. Успех → «Готово: вся библиотека открыта» и возврат туда, откуда пришли (карточка
   картинки — сразу с кнопкой «Вышивать»).
3. Отмена игроком → тихо назад на экран подписки, без уговоров.
4. Ошибка → понятная строка: нет RuStore, не вошли в RuStore, нет сети, платёж не прошёл —
   и что делать.

### Окончание подписки

- **Льготный период** (RuStore Pay не смог списать и повторяет, статус `grace`) — библиотека
  открыта, на экране «Узоры+» строка «Не удалось продлить подписку — проверьте способ
  оплаты в RuStore». **Приостановка** (`hold`) и **закрыта** (`closed`) — как окончание.
- Библиотека снова запирается по `access`; метки «Узоры+» возвращаются.
- **Начатые работы дошиваются**; готовые открываются и делятся, как прежде.
- Ни окна «Ваша подписка закончилась», ни уговоров: при следующем касании запертой
  картинки — обычная карточка с «Подробнее».

## Протокол

Сервера нет. RuStore Pay SDK для React Native (обёртка 11.1.0) — как в «Нардах»:
запрос товаров, покупка, список покупок и статус подписки; копируется их плагин
конфигурации ([`../02-architecture.md`](../02-architecture.md), «Подписка»). Необязательные
`appUserEmail` и `appUserId` в покупку не передаются. Перед интеграцией — перечитать
текущую документацию RuStore Pay по ссылкам из [`../10-money.md`](../10-money.md),
а не по памяти.

## Неудачные случаи

| Случай | Что происходит |
|---|---|
| RuStore не установлен или устарел | экран подписки: «Подписка оформляется через RuStore. Установите или обновите RuStore»; всё бесплатное работает |
| не вошли в RuStore | окно RuStore само просит войти; отказ — назад без ошибки |
| нет сети при покупке | «Нет связи — подписку оформить не получится. Вышивать бесплатные картинки можно и так» |
| подписка оплачена, а ответ потерялся | при следующем запуске и по «Восстановить покупки» RuStore Pay отдаёт покупку; права появляются |
| нет сети долго | `PlusState` действует до `until`, без срока — трое суток с последней проверки ([`../04-data-model.md`](../04-data-model.md)) |
| возврат денег через поддержку RuStore | при следующей проверке покупки нет — подписка кончилась, как обычно |
| сборка не из RuStore (APK из Releases) | экрана подписки нет; вместо «Подробнее» — «Подписка доступна в версии из RuStore» |

## Критерии приёмки

1. `access` запирает ровно то, что велит [`../08-game-design.md`](../08-game-design.md);
   тесты на все случаи зелёные ([`../06-testing.md`](../06-testing.md)).
2. В тестовом режиме RuStore Pay на телефоне: покупка месяца и года, восстановление после
   переустановки, льготный период (библиотека открыта), окончание подписки — начатая
   работа дошивается до конца.
3. Строка про подписку на «Готово» — не чаще раза в сутки и не в первые три дня; нигде
   больше подписка не предлагается сама (проверка сценарием).
4. На экране подписки — цена и срок, «продлевается сама», как отменить, «Восстановить
   покупки», ссылки на условия и политику; текст сверен юристом или владельцем
   с требованиями [`../10-money.md`](../10-money.md).
5. «Сохранить работы в файл» на одном телефоне → «Загрузить из файла» на другом:
   все работы на месте, готовые — готовы.

## Чего здесь нет

Пробного периода (ADR [0009](../adr/0009-honest-subscription.md)). Покупки «навсегда» и
разовых покупок коллекций — открытый вопрос владельца ([`../07-roadmap.md`](../07-roadmap.md)).
«Своего узора» — 1.1. Подписки в других магазинах нет и не планируется: там — только
распространение без денег ([`../10-money.md`](../10-money.md), «Другие магазины»).

**29.09.2026, 0.6.0** — «Перенос»: работы файлом, раньше подписки. Подписке нужны ИП и RuStore
Pay (В2), а перенос нужен и без неё: сменить телефон, вышивать то на компьютере, то на телефоне.

- В настройках раздел «Перенос»: «Сохранить работы в файл» и «Загрузить из файла»; «Восстановить
  покупки» появится вместе с подпиской.
- В файле, кроме работ, — свои узоры (`works/mine-<id>.json`): без узора его работу не открыть.
  Работа своего узора, которого нет ни в файле, ни на телефоне, пропускается.
- Совпавшие по id работы не дублируются: остаётся та, где вышито больше (перенос туда и обратно
  не теряет стежков; прежний файл стежков остаётся `.bak`).
- Файл проверяется строго (`src/engine/backup.ts`): id работ и узоров становятся именами файлов —
  только латиница, цифры и дефис; стежки должны разбираться и быть того же узора; «вышито» в
  указателе считается по стежкам файла. Испорченная работа или узор пропускаются, строка итога
  говорит, сколько не открылось; не файл «Узоров» — «Это не файл работ „Узоров“».
- Телефон: файл уходит в «Поделиться», выбор — системным окном Android (`File.pickFileAsync`
  из `expo-file-system`, без новых зависимостей и разрешений). Веб-версия: файл скачивается и
  выбирается с диска — так работы переезжают с компьютера на телефон и обратно.

**20.10.2026** — покупка через RuStore Pay. ИП и кабинет RuStore на ИП есть (В2), приложение в консоли
заведено (номер 2063773260, [`store/preorder.md`](../../store/preorder.md)); код перенесён из «Нард»
(`Nefeste/nardy` @ 63e8ee9) — по их работающему коду той же версии SDK: документация RuStore из среды
ассистента недоступна.

- **Сборка.** `plugins/with-rustore.js` (из «Нард») вписывает в `android/` то, что велит документация
  RuStore: maven-репозиторий, `ru.rustore.sdk-wrapper.react-native:pay:11.1.0`, пакет в
  `MainApplication`, возврат из приложения банка в `MainActivity`, в манифест — номер приложения
  (`console_app_id_value`) и свою схему `gornitsauzorypay`. Номер — переменная репозитория
  `RUSTORE_APP_ID`, в сборку — `EXPO_PUBLIC_RUSTORE_APP_ID` (`android.yml`). **Иначе, чем в «Нардах»:
  без номера плагин не вписывает ничего** — сборка та же, что до RuStore Pay, без SDK и его
  разрешений: сборка для проверки и закрытый тест не меняются. `android.yml` сверяет готовый APK:
  номер в манифесте есть ровно тогда, когда задана переменная; итоги и заметки релиза говорят, есть
  ли в сборке покупки.
- **Код денег — в `src/money/`** (путь владельца, устав ADR 0018), как в «Нардах»: `rustore.ts` —
  обёртка над нативным модулем, `rustoreRules.ts` — чистые правила ответов, `rustoreBilling.ts` —
  магазин по порту `src/state/billingApi.ts`. Экраны по-прежнему берут магазин из
  `src/state/billing.ts`: есть нативный модуль и номер — RuStore Pay, нет — «магазина нет», как раньше.
- **Цены** — `getProducts`: строка цены магазина как есть; копейки для «≈ 83 ₽ в месяц» — из этой
  строки (в каких единицах число `price` SDK, пример RuStore не говорит).
- **Покупка** — одна стадия, без `appUserId` и `appUserEmail`; после — отметка «выдано»
  (`ACKNOWLEDGED`) и срок из списка покупок. RuStore срока ещё не отдал — «действует» без срока:
  по правилам движка это трое суток с проверки, а следующая проверка срок узнает. После отказа,
  сбоя или обрыва связи игра спрашивает RuStore ещё раз: подписка могла оплатиться, а окно —
  закрыться раньше ответа («Неудачные случаи»). Отказ войти в RuStore — тихо, как отказ от оплаты.
- **Права** — `getPurchases`, подписки `uzory_plus_*`: `ACTIVE` — действует до `expirationDate`,
  `PAUSED` — приостановка (Hold), `CLOSED` — закрыта, прочее (счёт не оплачен, незнакомое) — подписки
  нет. Из нескольких — лучшая: действующая, из действующих — с дальней датой. `ACTIVE` с прошедшей
  или неразборчивой датой (списание за новый срок идёт) — без срока, трое суток с проверки.

**Как проверить на телефоне (критерий 2).** Названия пунктов консоли ассистент не видел —
**[сверить в консоли]**.

1. Владелец: GitHub → Settings → Secrets and variables → Actions → **Variables** →
   `RUSTORE_APP_ID` = `2063773260`.
2. В консоли RuStore: подписки `uzory_plus_month` (`P1M`) и `uzory_plus_year` (`P1Y`) по таблице
   «Товары RuStore Pay» в [`store/preorder.md`](../../store/preorder.md), без пробного и промо-периода.
   Тестовый режим — консоль → приложение → «Монетизация» → «Тестовые платежи» → «Тестировщики» →
   «Режим тестирования» для своего аккаунта (путь — по «Нардам», 23.10.2026). **Тестовые платежи работают
   только после модерации версии:** RuStore Pay сверяет подпись APK с версией в консоли. Поэтому покупка
   проверяется на сборке 1.0.0 между модерацией и публикацией — порядок в [`store/release.md`](../../store/release.md);
   на сборке до модерации платёж не пройдёт, и строка «Ответ RuStore» под причиной скажет почему.
3. Сборка — по тегу (PR выпуска сливает владелец). В итогах «Сборка apk» — строка «RuStore Pay:
   есть, приложение 2063773260», в заметках релиза — «Подписка „Узоры+“ — через RuStore Pay».
   Если сборка остановится на разрешении вне белого списка — его принёс SDK оплаты (в «Нардах» с
   RuStore Pay и рекламой появилось `RECEIVE_BOOT_COMPLETED`): решение владельца — в список
   (`android.yml`, [`../05-process.md`](../05-process.md), политика) или в `blockedPermissions`.
4. APK — на телефон с RuStore, вход в RuStore тем аккаунтом, что в тестовом режиме.
5. «Настройки» → «Узоры+»: цены — те, что в консоли; выбрать месяц → «Оформить» → окно RuStore →
   тестовая оплата → «Готово: вся библиотека открыта», экран — «„Узоры+“ действует до …». Чтобы
   видеть запертые картинки, как у игрока, — «Для проверки» → образец «Узоры+» → «Как в 1.0»
   (сборка 0.x иначе ничего не запирает).
6. Закрыть окно оплаты, не платя, — тихо назад; без сети — «Нет связи…».
7. Удалить игру, поставить заново → «Узоры+» → «Восстановить покупки» → «Покупки восстановлены».
8. Год — то же; отмена в RuStore («Подписки» → «Отменить») — доступ до конца срока, потом начатая
   работа дошивается, новая картинка «Узоры+» заперта.
9. Отключить RuStore (или проверить на телефоне без него) — «Подписка оформляется через RuStore.
   Установите или обновите RuStore»; всё бесплатное работает. Выйти из RuStore и нажать «Оформить» —
   окно RuStore само просит войти, отказ — тихо назад **[проверить]**.

**«Ответ RuStore»** (0.16.1, из «Нард» @ af8b683): RuStore Pay любую ошибку по дороге — сеть, отказ
сервера, номер приложения, подпись — отдаёт ответом «недоступно», и обёртка для React Native передаёт из
него только текст. Экран «Узоры+» показывает этот текст мелко под причиной — «Ответ RuStore: …» — когда цен
нет, когда платёж не прошёл и когда «Восстановить покупки» не смогло спросить RuStore; неудачная оплата
пишется в журнал сбоев. Знакомые тексты («RuStore not installed», «RuStore outdated») становятся причиной
«установите или обновите RuStore» (`causeOf` в `src/money/rustoreRules.ts`).
