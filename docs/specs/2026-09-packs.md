# Новые картинки по сети и счётчики

**Версия:** 0.4 **Состояние:** задумано

## Зачем

Обещание «новые картинки каждую неделю» не должно ждать модерации RuStore: картинки —
данные, а не код. Этот этап учит телефон раз в сутки спрашивать каталог и докачивать
новые наборы, а студию — выкладывать набор недели одной меткой в PR и видеть,
возвращаются ли люди (ADR [0007](../adr/0007-offline-first.md),
[0012](../adr/0012-stats-from-manifest.md)).

## Что увидит игрок

- Ничего, пока всё хорошо: новые картинки просто появляются в библиотеке с меткой «Новое».
- Строка на главном экране — только в трёх случаях ([`../03-server-api.md`](../03-server-api.md),
  «Ошибки»): «Новые картинки — в новой версии игры», «Не хватает места для новых картинок»,
  строка `notice` из каталога.
- В «О программе» — «Картинки обновлены: <дата последнего набора>».

## Данные

- `packs/`, `library.json` — [`../04-data-model.md`](../04-data-model.md).
- Хранилище: `catalogCheckedAt`, `catalogEtag`, `packFailures` (набор → число неудач подряд),
  счётчики суток ([`../04-data-model.md`](../04-data-model.md), «Счётчики суток»).

## Протокол

Каталог, наборы, параметры счётчиков, кэш — [`../03-server-api.md`](../03-server-api.md).
Новое на сервере — папка `/srv/gornitsa/uzory/v1/` (владелец — пользователь `deploy`)
и строки nginx в репозитории сайта. Папка лежит **вне** папки сайта `/var/www/gornitsa.games`:
автообновление сайта выкладывает свою папку через `rsync --delete` и стёрло бы в ней
всё чужое, в том числе наборы.

```nginx
location = /uzory/v1/catalog.json {
    root /srv/gornitsa;
    access_log /var/log/nginx/uzory-catalog.log uzory_stats;   # формат без $remote_addr
    add_header Cache-Control "no-cache" always;
    add_header X-Content-Type-Options "nosniff" always;
}
location = /uzory/v1/catalog.sig {
    root /srv/gornitsa;
    access_log off;                                            # второй запрос дня — не считаем
    add_header Cache-Control "no-cache" always;
    add_header X-Content-Type-Options "nosniff" always;
}
location /uzory/v1/packs/ {
    root /srv/gornitsa;
    access_log off;
    gzip on; gzip_types application/octet-stream;
    add_header Cache-Control "public, max-age=31536000, immutable" always;
    add_header X-Content-Type-Options "nosniff" always;
}
```

```nginx
log_format uzory_stats '$time_iso8601 "$request_uri" $status';
```

Свёртка — `server/stats/fold.ts` (Bun) по таймеру раз в сутки: журнал → CSV сумм
([`../04-data-model.md`](../04-data-model.md), «Счётчики на сервере») → удаление строк
старше семи дней. Выкладывается тем же `content.yml`.

## Неудачные случаи

Все случаи и поведение телефона — [`../03-server-api.md`](../03-server-api.md),
«Ошибки и неудачные случаи». Дополнительно:

- **Каталог выложен раньше набора** — не бывает: CI копирует наборы первыми
  ([`../05-process.md`](../05-process.md), «Выкладывание наборов»); если всё же случилось —
  набор не скачается по SHA-256 и будет скачан завтра.
- **Набор с картинкой, чей ключ уже есть на телефоне** (версия та же) — картинка не
  дублируется; байты узора сверяются, несовпадение — запись в журнал сбоев, остаётся
  прежний узор.
- **Сервер отдаёт HTML вместо JSON** (ошибка nginx, провайдерская заглушка) — каталог
  не разбирается и игнорируется.

## Критерии приёмки

1. Сквозной сценарий: поддельный сервер отдаёт каталог с новым набором — после запуска
   картинки есть в библиотеке с меткой «Новое»; набор с неверным SHA-256 не появляется,
   и библиотека не меняется; каталог с неверной подписью игнорируется.
2. Каталог запрашивается не чаще раза в сутки; без сети — ни одной ошибки на экране.
3. Строка запроса каталога содержит ровно параметры из [`../03-server-api.md`](../03-server-api.md);
   тест сверяет её с таблицей.
4. `content.yml` по метке `publish` выкладывает набор недели и каталог, затем скачивает
   их обратно и сверяет хеши; выложенный ранее набор не меняется.
5. Свёртка журнала на образце журнала даёт ожидаемый CSV; строки старше семи дней удалены;
   в CSV и в журнале нет адресов.
6. Политика конфиденциальности на сайте студии получает раздел «Узоры» с описанием
   счётчиков до выхода 1.0.

## Чего здесь нет

Уведомлений о новых картинках (ADR [0011](../adr/0011-calm.md)). Скачивания по мобильной
сети только по разрешению — наборы маленькие. Отдельного расписания загрузок: набор
скачивается, как только появился в каталоге, а в библиотеке показывается с даты `from`.
