# 0007. Библиотека — в приложении; новое — файлами с сервера студии в России; сервера с логикой нет

**Решили.**

- Вся библиотека на день сборки и календарь картинок дня на год вперёд лежат **в APK**.
  Без сети у игрока есть всё, кроме картинок, вышедших после его версии.
- Новые картинки — **наборы**: статические файлы на сервере студии (`gornitsa.games`,
  VPS в России, nginx), каталог раз в сутки ([`03-server-api.md`](../03-server-api.md)).
  Скачанное остаётся на телефоне навсегда.
- **Сервера с логикой нет**: ни профилей, ни учётных записей, ни облачных сохранений,
  ни проверки покупок на сервере. Сервер раздаёт файлы и пишет журнал запросов каталога
  без адресов (ADR [0012](0012-stats-from-manifest.md)).

**Почему.**

- «Работает без интернета» — обещание сайта студии, и жанру это важно: раскрашивают
  в метро, в самолёте, на даче.
- **Нечего утечь и нечего чинить ночью.** Нет базы игроков — на сервере нет персональных
  данных и нет протокола, который сервер обязан понимать у старых версий, как у «Вотчины»
  с 2.0.
- **Без VPN.** Сервер в России на том же VPS, что сайт студии: российские провайдеры
  с 2025 года замедляют Cloudflare (ADR 0005 «Нард»), а «не работает без VPN» — частая
  жалоба на зарубежные приложения в RuStore. Статика на nginx не требует ни нового сервера,
  ни денег.
- Новые картинки раз в неделю без выпуска версии в RuStore: модерация приложения — дни,
  а набор картинок — это данные. Каталог подписан ключом студии, а наборы сверяются
  по хешу из него: даже взломанный сервер не подсунет игре чужие картинки
  ([`03-server-api.md`](../03-server-api.md)).

**Платим.**

- **APK крупнее** на встроенный набор (бюджет 8 МБ) — [`02-architecture.md`](../02-architecture.md).
- **Нет облачного прогресса**: работы переезжают автобэкапом Android или файлом
  ([`04-data-model.md`](../04-data-model.md)). Телефон без сервисов Google и без файла —
  работы теряются вместе с телефоном.
- Исправить уже выпущенную картинку можно только новой версией узора
  (ADR [0010](0010-frozen-patterns.md)).
- Один VPS — одна точка отказа; но упавший сервер значит лишь «новые картинки придут
  позже», вышивать это не мешает.

**Когда пересмотреть.** Если появится то, что без сервера нельзя: облачный перенос работ
по коду (как «Перенос профиля» в «Вотчине»), общие события, подписка, которой нужна
проверка на сервере, — новая ADR, политика конфиденциальности и анкеты магазинов.
