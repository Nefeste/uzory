# 0014. `games.gornitsa.uzory` и постоянный ключ подписи — с первой сборки

**Решили.** Идентификатор приложения — **`games.gornitsa.uzory`**, по домену студии, как
`games.gornitsa.nardy` у «Нард» (их ADR 0017). Ключ подписи — постоянный **с первой
сборки**, отдельный от ключей других игр: плагин `with-release-signing` из «Вотчины»,
ключ в секретах CI, проверка отпечатка в CI. Релизная сборка без ключа не выходит
дальше проверки. Копия ключа и паролей — у владельца, отдельно от репозитория.

**Почему.**

- «Вотчина» заплатила за поздний постоянный ключ переустановкой у каждого игрока (её
  ADR 0013); «Нарды» и «Анамнез» взяли ключ с первой сборки. До ключа игроков нет —
  постоянный ключ сейчас ничего не стоит.
- Отладочный ключ шаблона общеизвестен: APK с тем же идентификатором, подписанный им,
  Android ставит обновлением — и тот получает работы игрока.
- Магазины не дают сменить ключ и идентификатор у опубликованного приложения; подписка
  в RuStore Pay привязана к приложению.
- Общий префикс `games.gornitsa` — у всех игр студии: по нему видно, чьё приложение,
  а домен принадлежит владельцу.

**Платим.** Потерять ключ — навсегда потерять возможность обновлять игру. Ошибка
в идентификаторе — тоже навсегда. Выбор идентификатора подтверждает владелец до
первой сборки ([`07-roadmap.md`](../07-roadmap.md), «Открытые вопросы»).
