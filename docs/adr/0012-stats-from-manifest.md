# 0012. Статистика — счётчики запросов каталога, без идентификаторов и SDK аналитики

**Решили.** Раз в сутки телефон спрашивает каталог новых картинок, и в строке запроса —
несколько обезличенных чисел о прошлом дне игры: версия, магазин, неделя установки,
сколько дней с установки, есть ли подписка, сколько картинок закончено и сколько минут
вышивали — корзинами ([`03-server-api.md`](../03-server-api.md), «Счётчики»). Сервер
пишет эти запросы в отдельный журнал **без адресов и заголовков**, раз в сутки сворачивает
в суммы и через семь дней стирает сырые строки. SDK аналитики (AppMetrica и подобные)
не подключаются.

**Почему.**

- Без удержания по неделям установки нельзя решать о ценах, бесплатной части и
  картинках — а это и есть деньги ([`10-money.md`](../10-money.md)). Консоль RuStore
  показывает установки и покупки, но не то, возвращаются ли люди вышивать.
- Запрос каталога идёт всё равно: счётчики не добавляют ни одного лишнего обращения
  в сеть, ни одной библиотеки и ни одного разрешения.
- **Связать запрос с человеком нечем**: нет ни номера установки, ни ключа, ни рекламного
  идентификатора, ни адреса. Это не персональные данные, и в политике это одна
  понятная фраза. «Нарды» решили похожую задачу пингом с номером установки (их ADR 0015);
  здесь обходимся без номера совсем.

**Платим.**

- **Нет воронок и событий внутри сессии**: где бросают картинку, какой экран непонятен —
  узнаём от тестировщиков и из отзывов.
- **Удержание приблизительное**: один телефон за день даёт один запрос, но без номера
  установки нельзя отличить двух игроков одной недели от одного, открывшего игру дважды
  после переустановки. Для решений масштаба «цена», «бесплатная часть» этого хватает.
- Игрок без сети не учитывается, пока не выйдет в сеть; его прошлые дни не досылаются.
- Настройка nginx для `/uzory/` живёт в репозитории сайта и правится там
  ([`05-process.md`](../05-process.md)).

**Когда пересмотреть.** Если понадобятся вопросы, на которые суммы не отвечают (путь
игрока до подписки, что открывают перед уходом), — новая ADR и строка в политике;
SDK с идентификаторами — только с согласием игрока.
