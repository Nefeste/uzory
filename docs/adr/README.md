# Принятые решения (ADR)

Короткие записки о решениях, которые дорого менять. Каждая отвечает на три вопроса:
что решили, почему, чем за это платим. Читать **до** того, как предлагать обратное.

Новая записка — новый файл `NNNN-краткое-название.md` по образцу соседних. Решения
не переписываются задним числом: если передумали, пишется новая записка со ссылкой
«заменяет NNNN», а у старой в заголовке появляется «(заменено NNNN)».

Многие решения унаследованы от «Вотчины», «Нард» и «Анамнеза»; где так, записка говорит,
что взято и что изменилось.
