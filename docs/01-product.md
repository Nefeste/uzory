# Что это за продукт

**«Узоры»** — раскраска по номерам для телефона в виде **вышивки крестиком**: картинка —
это схема на канве, клетки подписаны номерами нитей, игрок выбирает нить и «вышивает»
касанием или проводя пальцем. Издалека работа выглядит как настоящая вышивка, а когда
она закончена, игра показывает, «как вышивалось», и рассказывает о картине.

В библиотеке — **орнаменты по мотивам народной вышивки, русская живопись, сказочные
иллюстрации, Россия сто лет назад в цвете, цветы, природа и города**. Каждый день — новая
бесплатная картинка. Работает без интернета, без регистрации и **без рекламы**. Деньги —
подписка «Узоры+» через RuStore Pay: вся библиотека и новые картинки каждую неделю.

Это четвёртая игра студии «Горница» после «Вотчины», «Нард» и «Анамнеза». Так же, как
«Нарды», она с первого дня **должна зарабатывать** ([`10-money.md`](10-money.md)).
На сайте студии она уже обещана: [gornitsa.games](https://gornitsa.games/), раздел
«В планах», — и там же стоит пример-«пяльцы», по которому видно, как игра будет
устроена. Обещания сайта — это обязательства: всё, что там написано, в игре должно быть.

## Название

Рабочее название — **«Узоры»**. В магазине — **«Узоры — раскраска по номерам»**:
главные слова поиска стоят в названии. «Вышивка» — в коротком описании и ключевых словах.

Название окончательно выбирает владелец. До выбора проверить: знаки в классах МКТУ 9
и 41 по базе ФИПС (слово «узоры» общеупотребимое, но знак с ним может быть), выдачу
RuStore по словам «узоры» и «раскраска по номерам», как название смотрится рядом
с соседями. В коде и документах проект называется **«Узоры»** (`uzory`), чтобы смена
названия в магазине не требовала правок по репозиторию.

## Для кого

Портреты — гипотезы, их проверяют первые недели после выхода ([`11-market.md`](11-market.md)).

1. **Женщина 35–65 лет, которая отдыхает с телефоном.** Вечером, в дороге, перед сном
   раскрашивает или собирает пазлы. Хочет красиво и спокойно; не хочет рекламы после
   каждой картинки, «пробной недели», которая сама превращается в платную, и поиска
   последней клетки с лупой. Это ядро аудитории RuStore и главный источник подписок.
2. **Та, кто вышивает по-настоящему.** Вышивка крестиком — массовое хобби, и наборы
   для вышивки по картинам Шишкина продаются готовыми ([`11-market.md`](11-market.md)).
   В игре она узнаёт своё: канва, нити с названиями, схема, крестики. Игра не заменяет
   иглу, а дополняет её — когда устали глаза или руки, в дороге, «примерить» картину.
3. **Бабушка с внуком.** Крупные клетки, три-четыре нити, картинка за пять минут; ничего
   страшного и ничего платного в детских картинках. Категория 0+.
4. **Тот, кто любит русскую живопись.** Для него картинка — повод узнать, кто и когда её
   написал и где она висит: у каждой картины есть короткий рассказ.

## Что обещаем игроку

- **Спокойно.** Ни таймеров, ни «энергии», ни жизней, ни наказания за пропущенный день.
  Картинки не исчезают, ничего не «сгорает», торопиться некуда. Это обещание сайта
  («никакой спешки»), и оно проверяется любым решением ([`08-game-design.md`](08-game-design.md)).
- **Без рекламы.** Ни роликов, ни баннеров, ни «посмотри рекламу, чтобы открыть».
  Решение и его цена — ADR [0008](adr/0008-no-ads.md).
- **Картинка дня — бесплатно, каждый день и навсегда.** Прошлые картинки дня не пропадают:
  пропустили неделю — вышиваете, когда удобно.
- **Честная подписка.** Цена и срок — крупно, до нажатия; пробных периодов, которые сами
  становятся платными, нет; отменить можно в RuStore в любой момент, и игра говорит где.
  Начатое по подписке можно дошить и после её окончания; законченное остаётся навсегда
  ([`10-money.md`](10-money.md), ADR [0009](adr/0009-honest-subscription.md)).
- **Работает без интернета.** Библиотека лежит в приложении; новые картинки скачиваются,
  когда есть сеть, и остаются на телефоне.
- **Без регистрации.** Нет ни профиля, ни почты, ни входа через соцсети. Покупка привязана
  к учётной записи RuStore и восстанавливается на новом телефоне.
- **Удобно глазам и пальцам.** Крупные номера, приближение двумя пальцами, «Лупа» сама
  находит оставшиеся клетки нити, ошибиться клеткой нельзя.
- **Работа не теряется.** Она записывается сама, пока вы вышиваете, и сразу, когда вы
  уходите с экрана; работы переносятся на новый телефон резервной копией Android или файлом.
- **Настоящее, а не сгенерированное.** Картины — подлинные работы художников в общественном
  достоянии, фотографии — свои или старые снимки в общественном достоянии, орнаменты —
  по мотивам народной вышивки. Картинок из генераторов изображений нет
  (ADR [0006](adr/0006-content-sources.md)).

## Чего в продукте сознательно нет

- **Рекламы** — никакой (ADR [0008](adr/0008-no-ads.md)).
- **Игровой валюты, подсказок за деньги, «бомб» и «волшебных палочек» в магазине.** Все
  инструменты бесплатны и без ограничений; платно — только доступ к картинкам.
- **Таймеров, энергии, серий «не пропусти день», уведомлений «вернись».** В 1.0
  уведомлений нет вовсе ([`08-game-design.md`](08-game-design.md), «Что возвращает в игру»).
- **Регистрации, профиля в сети, таблиц лидеров, соревнования.** Игра для себя.
- **Загрузки чужих картинок и обмена ими.** Нет пользовательского контента — не нужна
  модерация. «Свой узор из фотографии» (1.1) остаётся на телефоне того, кто его сделал.
- **Картинок из генераторов изображений, с брендами, людьми наших дней крупным планом,
  наготой, религиозными образами, политикой и войной** — правила отбора в
  [`09-content.md`](09-content.md).
- **Сервера с логикой.** Есть только раздача файлов с новыми картинками; игра не знает,
  кто вы (ADR [0007](adr/0007-offline-first.md)).
- **iOS в 1.0.** Основной канал — RuStore, это Android. Веб-сборка — только для
  автоматических проверок, как в «Анамнезе».

## Как называются вещи

Термины в коде и в интерфейсе должны совпадать. Принятый словарь:

| В интерфейсе | В коде | Что это |
|---|---|---|
| картинка | picture | запись библиотеки: название, автор, коллекция, права, узор |
| узор (схема) | pattern | сетка клеток с номерами и палитра; у картинки ровно один узор определённой версии |
| клетка | cell | одна клетка сетки; номер клетки в коде — индекс `y × ширина + x` |
| канва | canvas | поле, на котором вышивают: сетка, фон, крестики |
| нить | thread | цвет палитры: номер, название, цвет |
| номер | number | номер нити, которым подписана клетка; в коде `thread + 1` |
| палитра | palette | все нити узора |
| стежок, крестик | stitch | закрашенная клетка |
| касание | tap | вышить одну клетку |
| кисть | brush | вышивать, проводя пальцем: закрашиваются только клетки выбранной нити |
| заливка | fill | двойное касание: вся связная область этого номера |
| лупа, «Где ещё?» | finder | показывает оставшиеся клетки выбранной нити |
| пипетка | pick | долгое касание клетки выбирает её нить |
| работа | work | вышивание одной картинки: начатая или законченная |
| «Мои работы» | works | начатые и законченные работы |
| картинка дня | daily | бесплатная картинка на каждый день, одна у всех |
| календарь | calendar | все картинки дня с первого запуска игры, прошлые тоже |
| коллекция | collection | тематический набор картинок библиотеки |
| библиотека | library | все картинки, какие знает игра |
| набор | pack | файл с картинками: встроенный в приложение или скачанный |
| «Как вышивалось» | replay | повтор всех стежков работы за 8–12 секунд |
| стиль | style | как рисуются стежки: «Крестик», «Мозаика»; из одних данных |
| размер | size | «Малая», «Средняя», «Большая» — по числу клеток ([`08-game-design.md`](08-game-design.md)) |
| о картине | about | несколько фраз: кто, когда, где хранится |
| «Узоры+» | plus | подписка: вся библиотека и новые картинки в день выхода |
| свой узор | custom | узор из своей фотографии (1.1) |
