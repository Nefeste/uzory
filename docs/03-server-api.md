# Раздача картинок

**Состояние:** телефонная часть — с 0.7.0 (`src/state/net.ts`: каталог, подпись, наборы),
счётчики — с 0.8.0 (`src/state/counters.ts`, свёртка — `server/stats/fold.ts`); сборка набора
недели и выкладка — с 0.13.0 (`tools/content/week.ts`, `content.yml`), первая выкладка на сервер —
после В9 и ключа подписи (В18). Документ описывает то, что есть, и целевой протокол
1.0 там, где кода ещё нет.

У «Узоров» нет сервера с логикой (ADR [0007](adr/0007-offline-first.md)). «Протокол» —
это договор о **статических файлах**, которые CI кладёт на сервер студии, а телефон
читает: каталог и наборы. Сервер ничего не вычисляет, не принимает и не хранит об
игроках — кроме журнала запросов каталога, из которого получаются обезличенные
счётчики (ADR [0012](adr/0012-stats-from-manifest.md)).

Адрес — `https://gornitsa.games/uzory/v1/`. Всё — через HTTPS. Наборы неизменяемы: новое
содержимое — новое имя файла. Переписываются только каталог и его подпись.

## Что лежит на сервере

```
/uzory/v1/catalog.json                каталог: наборы, календарь, минимальная версия
/uzory/v1/catalog.sig                 подпись каталога (Ed25519)
/uzory/v1/packs/<id>.<sha8>.pack      наборы; sha8 — первые 8 знаков SHA-256 файла
```

Файлы лежат на сервере в `/srv/gornitsa/uzory/v1/`, вне папки сайта
([спецификация](specs/2026-09-packs.md)). Страница игры `gornitsa.games/uzory/` —
обычная страница сайта студии, из его репозитория. Рядом, но к раздаче отношения не имеет:
`gornitsa.games/uzory/test/` — закрытая веб-версия для владельца, статические файлы под
паролем ([спецификация](specs/2026-09-web.md)); сервер берёт её из ветки `vps`.

| Файл | Кэш | Размер |
|---|---|---|
| `catalog.json`, `catalog.sig` | `Cache-Control: no-cache` (с `ETag`) | 5–30 КБ; 88 байт |
| `packs/*.pack` | `Cache-Control: public, max-age=31536000, immutable` | набор недели — 50–500 КБ, встроенный — около 2 МБ |

## Каталог

`GET /uzory/v1/catalog.json?v=1.0.0&s=rustore&c=2026-10-05&d=3&p=0&f=2&m=3`

Параметры — только для счётчиков; ответ от них не зависит. Смысл и почему в них нет
ничего, что узнаёт игрока, — ниже, «Счётчики».

```json
{
  "format": 1,
  "minApp": "1.0.0",
  "packs": [
    { "id": "base-1.0", "file": "packs/base-1.0.3f2c9a1b.pack",
      "sha256": "3f2c9a1b…(64)", "bytes": 2104331, "builtin": true },
    { "id": "w2026-41", "file": "packs/w2026-41.a91e0c77.pack",
      "sha256": "a91e0c77…(64)", "bytes": 88120, "from": "2026-10-12" }
  ],
  "calendar": { "pack": "w2026-41", "until": "2027-02-14" },
  "notice": null
}
```

- `format` — номер формата каталога. Телефон, который не знает этот номер, каталог
  не трогает и живёт тем, что уже скачал.
- `minApp` — ниже этой версии новые наборы не подходят (новый формат узора); телефон
  говорит «Новые картинки — в новой версии игры. Обновите её в RuStore» и больше ничего
  не меняет. Всё скачанное раньше работает.
- `packs` — все наборы, выпущенные когда-либо, в порядке выхода. `builtin: true` —
  набор уже лежит в APK этой версии, скачивать не нужно. `from` — с какой даты набор
  показывается в библиотеке (набор можно выложить заранее).
- `calendar` — какой набор несёт самый длинный календарь картинок дня и до какой даты
  он расписан; каждый набор недели продлевает его ([`09-content.md`](09-content.md),
  «Календарь картинок дня»).
- `notice` — короткая строка для главного экрана («Новые картинки задерживаются —
  неделя праздников»); в 1.0 используется только вручную, `null` почти всегда.

Телефон спрашивает каталог **не чаще раза в сутки** — при первом запуске за день, если
есть сеть; без сети — не спрашивает и не жалуется. Параметры счётчиков идут только
в первой попытке дня; повтор после неудачи — без них, чтобы день не посчитался дважды. «Обновить» руками нет: новые картинки
приходят раз в неделю, торопиться некуда.

## Подпись каталога

Каталог подписан: `catalog.sig` — подпись Ed25519 точных байтов `catalog.json` в base64.
Открытый ключ зашит в приложение (два — нынешний и следующий, для смены ключа), закрытый —
секрет CI ([`05-process.md`](05-process.md)). Телефон проверяет подпись **до** разбора
каталога; не совпала — каталог игнорируется, в журнал сбоев — запись. Наборы проверяются
по SHA-256 из подписанного каталога, поэтому подпись защищает всю цепочку: даже взломанный
сервер не подсунет в библиотеку игры для детей чужие картинки. Библиотека подписи — чистый
JS (`@noble/ed25519`), работает в Hermes.

## Набор

`GET /uzory/v1/packs/<id>.<sha8>.pack` — двоичный файл, формат — [`04-data-model.md`](04-data-model.md),
«Набор». Телефон:

1. скачивает во временный файл;
2. сверяет размер и SHA-256 с каталогом; не совпало — файл удаляется, попытка — завтра;
3. разбирает и проверяет каждый узор (размеры, номера нитей в пределах палитры);
4. только потом переносит в `packs/` и добавляет картинки в библиотеку.

Сбой на любом шаге не трогает библиотеку. Наборы качаются по одному, в фоне экрана,
только пока игра открыта; на мобильной сети — тоже (набор — от сотен килобайт до нескольких
мегабайт с огромными картинами).

## Счётчики

Раз в сутки телефон всё равно спрашивает каталог, и этот запрос несёт обезличенные
сведения о прошлом дне игры — последнем дне, когда игру открывали и о котором ещё
не сообщали. Решение и его цена — ADR [0012](adr/0012-stats-from-manifest.md).

| Параметр | Что | Пример |
|---|---|---|
| `v` | версия приложения | `1.0.0` |
| `s` | магазин сборки: RuStore, APK из Releases, закрытая веб-версия | `rustore`, `apk`, `web` |
| `c` | **неделя** установки — дата её понедельника | `2026-10-05` |
| `d` | сколько дней прошло с установки: 0–7 точно, дальше корзины `8-13`, `14-29`, `30-59`, `60+` (в адресе — `60%2B`) | `3` |
| `p` | действует ли подписка | `0` / `1` |
| `f` | сколько картинок закончено за прошлый день игры: 0, 1, 2, 3–5, 6+ (номер корзины) | `2` |
| `m` | сколько минут вышивали за прошлый день игры: 0, 1–5, 6–15, 16–30, 31–60, больше 60 (номер корзины) | `3` |

Здесь нет ни номера установки, ни ключа, ни рекламного идентификатора, ни модели
телефона: связать запрос с человеком нечем. Неделя установки вместо дня и корзины вместо
точных чисел — чтобы сведений было ровно столько, сколько нужно для решений, и не больше.
Как из этого считается удержание — [`05-process.md`](05-process.md), «Счётчики».

На сервере для `/uzory/v1/catalog.json` включён отдельный журнал, где нет адреса
и заголовков, — только время, строка запроса и код ответа. Раз в сутки скрипт
сворачивает его в таблицу сумм и удаляет исходные строки старше семи дней.

## Ошибки и неудачные случаи

| Что случилось | Что делает телефон |
|---|---|
| нет сети, таймаут, ответ не `200` | ничего не показывает; повтор — при следующем запуске, но не чаще раза в час, без параметров счётчиков |
| подпись каталога не сошлась | игнорирует каталог; в журнал сбоев — запись; повтор — завтра |
| каталог не разбирается, неизвестный `format` | игнорирует; в журнал сбоев — запись |
| набор не совпал по SHA-256 или не разобрался | удаляет файл; повтор — завтра; после трёх неудач подряд — запись в журнал сбоев |
| `minApp` выше версии приложения | строка на главной: «Новые картинки — в новой версии игры»; скачанное работает |
| на телефоне мало места | набор не скачивается; строка: «Не хватает места для новых картинок» |

## Совместимость

- `format` каталога и формат набора меняются только добавлением: новые поля старые
  телефоны пропускают. Несовместимое изменение — новый путь `/uzory/v2/`, а `/v1/`
  продолжает раздавать то, что понимают старые версии, пока они живы.
- Выложенный набор не удаляется и не заменяется никогда: файл с тем же именем — те же байты.
  Исправление картинки — новая версия узора в новом наборе (ADR [0010](adr/0010-frozen-patterns.md)).
