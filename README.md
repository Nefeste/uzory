# Узоры

Раскраска по номерам в виде **вышивки крестиком** — четвёртая игра студии «Горница»
([gornitsa.games](https://gornitsa.games/)) после «Вотчины», «Нард» и «Анамнеза». Картинка —
схема на канве, клетки подписаны номерами нитей; выбираете нить и вышиваете касанием или
проводя пальцем. Орнаменты по мотивам народной вышивки, русская живопись, сказочные
иллюстрации, Россия сто лет назад в цвете, цветы, природа и города. Новая картинка
каждый день, спокойная музыка, никакой спешки. Без интернета, без регистрации, без рекламы;
подписка «Узоры+» через RuStore Pay. Android, RuStore. Expo / React Native / TypeScript / Skia.

**Состояние:** спецификация готова, кода нет. Следующий шаг — этап 0
([`docs/07-roadmap.md`](docs/07-roadmap.md)): прототипы канвы и сборки картинок —
у ассистента; название, снимки, музыка, опорный телефон, RuStore Pay на ИП — у владельца.

## Чем отличается

1. **Вышивка, а не «ещё одна раскраска».** Канва, нити с названиями, крестики; после
   последнего стежка — «Как вышивалось» и рассказ о картине. Игровая вышивка в RuStore
   почти пуста, а вышивальщицы там есть ([`docs/11-market.md`](docs/11-market.md)).
2. **Без рекламы и без ловушек.** Ни одного ролика; картинка дня бесплатно каждый день
   и навсегда; подписка без пробной недели с автосписанием, начатое дошивается и после неё.
3. **Бережно к глазам и времени.** Крупные номера, ошибиться клеткой нельзя, «Где ещё?»
   находит последние клетки, вся библиотека работает без интернета, ничего не сгорает.
