# Узоры

Раскраска по номерам в виде **вышивки крестиком** — четвёртая игра студии «Горница»
([gornitsa.games](https://gornitsa.games/)) после «Вотчины», «Нард» и «Анамнеза». Картинка —
схема на канве, клетки подписаны номерами нитей; выбираете нить и вышиваете касанием или
проводя пальцем. Орнаменты по мотивам народной вышивки, русская живопись, сказочные
иллюстрации, Россия сто лет назад в цвете, цветы, природа и города. Новая картинка
каждый день, спокойная музыка, никакой спешки. Без интернета, без регистрации, без рекламы;
подписка «Узоры+» через RuStore Pay. Android, RuStore. Expo / React Native / TypeScript / Skia.

**Состояние** — версия, этап, что дальше и что ждёт владельца — в [`STATUS.md`](STATUS.md).

## Чем отличается

1. **Вышивка, а не «ещё одна раскраска».** Канва, нити с названиями, крестики; после
   последнего стежка — «Как вышивалось» и рассказ о картине. Игровая вышивка в RuStore
   почти пуста, а вышивальщицы там есть ([`docs/11-market.md`](docs/11-market.md)).
2. **Без рекламы и без ловушек.** Ни одного ролика; картинка дня бесплатно каждый день
   и навсегда; подписка без пробной недели с автосписанием, начатое дошивается и после неё.
3. **Бережно к глазам и времени.** Крупные номера, ошибиться клеткой нельзя, «Где ещё?»
   находит последние клетки, вся библиотека работает без интернета, ничего не сгорает.

## Как собрать

```bash
npm ci
bun tools/content/build.ts          # картинки → встроенный набор (без него приложение не собирается)
npx tsc --noEmit && npx tsc --noEmit -p tools && npm run lint && bun test tools/test
npm run export:web && npm run e2e   # веб-сборка и сценарий Playwright
UZORY_WEB_BASE=/uzory/test npx expo export --platform web --output-dir dist-site   # сборка для сайта
E2E_DIST=dist-site E2E_BASE=/uzory/test npm run e2e                                  # сценарий по ней
bun tools/content/sheet.ts          # лист превью картинок → dist/sheet/
FFMPEG=/путь/к/ffmpeg bun tools/audio/music.ts   # пьесы из assets/music/music.yaml → .webm
```

На каждый PR CI проверяет типы, линтер и тесты (`.github/workflows/pr.yml`); кто сливает —
по уставу ([`docs/05-process.md`](docs/05-process.md), «Ветки»). APK (AAB — нет, пока нет Google Play) CI (`android.yml`) собирает
на тег версии `vX.Y.Z` — только с картинками и пьесами с «да» владельца (`--release`) и
с постоянным ключом из секретов репозитория (там же, «Секреты»);
без ключа APK для телефона нет: файл только проверяется (размер, 16 КБ, разрешения) и не
выкладывается. Веб-сборка для сайта — раз в сутки, если `main` ушёл вперёд, и вручную
(`site.yml`): после сценария в браузере она уходит в ветку `vps`, зашифрованная ключом
сервера; сервер выкладывает её на <https://gornitsa.games/uzory/test/> под паролем
([`docs/specs/2026-09-web.md`](docs/specs/2026-09-web.md)).

## Версии

### Следующая версия

- **Подписку «Узоры+» можно оформить** — в сборке, где есть номер приложения в RuStore: на месяц или
  на год, через RuStore Pay, с ценой из RuStore. «Восстановить покупки» спрашивает RuStore заново;
  если подписка оплачена, а окно оплаты закрылось раньше ответа, — она всё равно появится. Без
  RuStore на телефоне экран «Узоры+» так и говорит: «Установите или обновите RuStore». В сборке без
  номера приложения всё как прежде: покупок нет, экран «Узоры+» — образец.

### 0.15.9 — 26 листов «Цветов» пересобраны: лепестки не сливаются с листьями

Решение владельца 17.10.2026 (issue 88). 26 выпущенных малых «Цветов» — ботанические листы — были
собраны с порогом различимости малой картинки, и соседние цвета сливались: у «Лилии-саранки» было три
нити, у тюльпана «Адмирал Винкель» пёстрые перья ушли в бледно-розовый. Теперь у них порог по сетке,
как у листов пачки 5: 5–13 нитей вместо 3–7. Заметнее всего изменились «Рябчик императорский»
(оранжевые колокольчики), тюльпаны и «Нарцисс тацетта». Прежние узоры остались в игре: начатые на них
работы открываются как были.

### 0.15.8 — календарь картинок дня: прошедшие дни закреплены, «Детям» — не в календаре

Решения владельца 17.10.2026 (issues 87 и 89). Прошедшие дни календаря картинок дня больше не
меняются: раньше календарь собирался из карточек заново, и новое «да» меняло картинки уже прошедших
дней. Теперь они записаны в `content/calendar.yaml` — по 18 октября, как в APK 0.15.6, — и сборка
продолжает календарь со следующего дня. Перед правкой, которая сдвигает календарь, ассистент
дописывает туда новые прошедшие дни: `bun tools/content/calendar.ts --write`.

Картинок «Детям» в календаре больше нет — ни в расписании, ни за его концом: они бесплатны всегда, и
их день ничего не дарил. Прошедшие дни с ними остались как были. Календарь выпуска стал короче: 132
дня, по 6 февраля 2027 года (было 157, по 3 марта).

### 0.15.7 — «Поделиться» и «Как вышивалось» у любой готовой работы

Раньше «Как вышивалось» и «Поделиться» были только на экране «Готово» сразу после последнего стежка:
после «Дальше» к ним было не вернуться (просьба владельца 17.10.2026). Теперь касание готовой работы в
«Моих работах» снова открывает «Готово» с этой работой: «Как вышивалось», «Поделиться» и «О картине» на
месте, вместо «Дальше» — «Вышить ещё раз» (она ведёт на карточку картинки), стрелка «назад» возвращает
на вкладку «Готовые». В веб-версии у своего узора с готовой работой — кнопка «Готовая работа».

На «Готово» в шапке появились «Настройки»: можно включить или выключить «Стежки на картинке
„Поделиться“», вернуться и поделиться той же работой ещё раз — разница видна сразу.

### 0.15.6 — «Лист узоров» удобнее для разбора

В «Листе узоров» появился фильтр «Без «да»»: в нём только картинки, которых ещё нет в выпуске, — запас
и музейные картины. Раньше их приходилось искать среди всех 382.

В фильтре «Без отметки» отмеченная картинка больше не пропадает сразу: она остаётся на экране, пока не
сменят фильтр или коллекцию. Поэтому после «Нет» можно спокойно дописать, что поправить.

### 0.15.5 — комментарий к картинке в «Листе узоров»

У каждой картинки в «Листе узоров» под «Да», «Нет» и «Позже» теперь есть короткое поле: что
поправить. По одному «Нет» не понять, что с картинкой не так, — просьба владельца 16.10.2026.
Комментарий хранится на телефоне или в браузере вместе с отметками. «Скопировать решения» пишет
его после названия картинки, например: `Нет (1): Розетка (rozetka) — «мелко, не видно лепестков»`.
Картинки, у которых есть только комментарий, без отметки, идут в текст отдельной строкой.

Отметка и комментарий теперь стоят под карточкой: нажатие на них картинку не открывает, её
открывают превью и название.

### 0.15.4 — кресты на главах, головы зверей и птиц

На «Успенском соборе Трифонова монастыря» появились кресты. Линия креста на снимке тоньше клетки
узора, и клетка брала цвет неба: три чёрные главы стояли без крестов. Теперь каждый крест
вышивается тёмной нитью — столб и перекладины. У «Храма Веры, Надежды, Любови и матери их Софии»
главы стали золотыми, а были серо-бурыми.

У зверей и птиц, у которых рамка глаза в 0.15.1 не помогла, — своя рамка вокруг головы, как вокруг
лиц в 0.15.3. У «Селезня на берегу» голова стала изумрудной, с белым ошейником, у «Лошади» белая
проточина идёт ото лба до носа, у «Белки у кормушки» голова рыжая, а не серое пятно. Указание
владельца: «важные части — это например лица или другие элементы узнаваемости объектов».

Начатые работы не пропадут: прежние узоры этих снимков остались в игре, и работа, начатая на прежнем
узоре, открывается и дошивается на нём.

это например лица».

Начатые работы не пропадут: прежние узоры этих снимков остались в игре, и работа, начатая на прежнем
узоре, открывается и дошивается на нём.

### 0.15.2 — «Замер прокрутки» в «Для проверки»

В разделе «Для проверки» на главной — «Замер прокрутки». Вся библиотека сама листается вниз до
конца и обратно со скоростью быстрого взмаха, пока превью ещё не нарисованы, а на экране — сколько

уже с «Вышивать». Покупка появится в сборке для RuStore после В2; пока её проходит только сценарий в
веб-версии с заглушкой магазина.

### 0.15.1 — старинные схемы без белых точек, у зверей и птиц на снимках — глаза

В «Шпице на подушке», «Охотничьей собаке», «Розах» и «Кайме с акантом» шерсть, трава и листья были
в белых точках: часть клеток рисунка сборка принимала за бумагу схемы, и они оставались невышитыми.
Теперь эти клетки вышиваются: шерсть ровная, трава зелёная, у шпица появился красный язык, а
прожилки аканта — светлыми стежками. Фон — кольцо хвоста, небо между лап, поляны между листьями —
по-прежнему не вышивается. Заметил владелец.

У кошек и галок на снимках появились глаза. Глаз меньше клетки узора, и раньше он пропадал в
шерсти: у «Кота в окне» глаз не было вовсе. Теперь глаз вышивается тёмной нитью, а у галок —
светлой, как на снимке. Так стало у семи снимков: «Кот в окне», «Кошка на скамейке», «Кошка в
лопухах», «Рыжая кошка», «Галка у кормушки», «Галка у пруда» и «Селезень у пруда». Заметил владелец.

Начатые работы не пропадут: прежние узоры этих схем и снимков остались в игре, и работа, начатая
на прежнем узоре, открывается и дошивается на нём.

### 0.15.0 — «Свой узор» ярче, стежки на «Поделиться» — по желанию, музыка в APK

«Свой узор» собирается так же, как снимки «Природы» и «Городов» в 0.14.7: цвет клетки — того, чего
в ней больше, а не среднее, и узор на 15 % насыщеннее. Листва и лес рассыпаются на мелкие пятна
реже: «Зонтики в парке» теперь подходят и без упрощения. Сохранённые раньше свои узоры не меняются —
хранится узор, а не снимок. «Карточка для библиотеки» записывает и новый способ сборки, так что снимок
из инструмента соберётся в библиотеке тем же узором.

Картинка «Поделиться» теперь сразу — ровными клетками цвета: так она ярче в маленьком превью.
Кому нужны стежки, включает в настройках «Стежки на картинке „Поделиться“» — работа будет крестиком
или плиткой, как выбран стиль. Так решил владелец.

Музыка вернулась в APK: владелец дал «да» всем пяти пьесам — Бородину, Глазунову, Шопену, Баху и
Григу. До этого они звучали только в сборках для проверки.

### 0.14.7 — снимки «Природы» и «Городов» ярче и чётче

Все 63 снимка владельца в «Природе» и «Городах» собраны заново. Раньше цвет клетки был средним
по её площади: лист, небо и ветка в одной клетке смешивались в мутную оливу, а края яблок,
лепестков и наличников расплывались. Теперь клетка берёт цвет того, чего в ней больше, и узор
на 15 % насыщеннее. «Райские яблочки» и рябина стали алыми, у кошки на скамейке видны рыжие
пятна, у наличников — белые рамки. Выбрал владелец по листу всех 63 снимков «как было / как стало».

Начатые работы не пропадут: прежние узоры этих снимков остались в игре, и работа, начатая на
прежнем узоре, открывается и дошивается на нём. Новые работы начинаются на новом узоре.

### 0.14.6 — «Поделиться» не бледнеет

Картинка «Поделиться» больше не бледнеет. У средних и больших узоров клетка на ней — от 14 до
43 точек, и смотрят её целиком, так что глаз смешивает клетку в один цвет. Крестик закрывал
72 % клетки, остальное было светлой канвой. До глаза доходило 30–60 % насыщенности нити:
тёмно-зелёная нить становилась бледно-оливковой, чёрная — серой, а канва между стежками
складывалась в сетку. Теперь на клетке мельче 44 точек стежки шире, а канва между ними в тени
нити, и клетка издалека почти того же цвета, что нить. Прежний крестик остался на крупной
клетке: на «Поделиться» малых узоров до 36 клеток по длинной стороне (детские картинки, многие
орнаменты) и на канве при вышивании на телефоне. Узоры не изменились, начатые работы
открываются как раньше.

### 0.14.5 — 17 снимков «России в цвете» в выпуске

В «Россию в цвете» пришли все 17 снимков Прокудина-Горского, ждавших отбора: Онежское озеро
и озеро Стерж, Златоуст, Касли и река Сатка на Урале, Бешеная балка на Кавказе, Пермь и мост
через Каму, Тобольск с колокольни, Тверь и Зубцов на Волге, шлюз на Шексне, сенокос и жатва,
гранаты и сладкий перец в саду. «Да» всем дал владелец, у каждого снимка есть рассказ «О картине».
В выпуске теперь 313 картинок, в «России в цвете» — 67 снимков. Узоры прежних картинок не
изменились. Календарь картинок дня тоже прежний: снимки большие, а в календарь идут малые и
средние узоры.

### 0.14.4 — бесплатные картинки в каждой коллекции, рассказы о картинах, стежки на «Поделиться»

Картинка «Поделиться» показывает работу в выбранном стиле — крестиками или плиткой — уже с клетки
в 14 точек, а не с 18, как номера на канве: номеров на законченной работе нет. Так стежки видны
у узоров до 114 клеток по длинной стороне — у 190 картинок из 296 в выпуске (было 162). У самых больших
картин клетка мельче, и они, как и раньше, — ровным цветом.

Без подписки в каждой коллекции открыты первые пять картинок. Но в «России в цвете» и «Живописи»
таких до сих пор не было, в «Природе» было четыре, в «Городах» — две. Теперь бесплатны «Нилова
пустынь на Селигере», «Крестьянские девушки», «Девушка с земляникой», «Торговец дынями. Дыни» и
«Водяные лилии» в «России в цвете», «Ледоход на Вятке» в «Природе», «Ротонда в Александровском
саду», «Дом с наличниками» и «Ретро-троллейбус» в «Городах» и все три картины «Живописи». Выбрал их
владелец. В своих коллекциях они теперь первые и без метки «Узоры+». Узоры не изменились: начатые
работы открываются как прежде.

У картин «Живописи» и снимков «России в цвете» в «О картине» появился рассказ — две-четыре фразы о
том, что на снимке, где и когда снято и какая у места или ремесла история. Например, что Торжок
славился шитьём золотом по бархату, а на Чусовой опасные скалы звали бойцами. Каждый рассказ написан
своими словами по двум открытым источникам: странице Библиотеки Конгресса или Метрополитен-музея и
энциклопедии.

На «Готово» время — минуты, в которые ложились стежки, а не от первого стежка до последнего: большую
картину вышивают неделями, и раньше она показала бы тысячи минут. Число стежков — с пробелом между
разрядами и в нужном падеже: «116 640 стежков · 8,5 часа», «121 стежок · 3 минуты». У работ, начатых
до этой версии, минут нет, и на «Готово» у них только число стежков. Процент на маленькой плитке
календаря больше не переносится на вторую строку.

Снимки для RuStore и сайта пересняты по спецификации 1.0: шесть кадров — вышивание, большая работа
издалека, «Готово», библиотека, календарь и «О картине».

Файл огромной картины во время вышивания больше не собирается заново. Раз в секунду игра собирала
файл работы целиком. У законченной картины 852 × 556 это сотни килобайт: без JIT, как на телефоне,
сборка шла 110–150 мс при пределе записи 20 мс. Теперь файл растёт вместе с работой: заново
собирается только штрих, который ещё идёт, — меньше миллисекунды. Формат файла тот же, начатые
работы открываются как прежде.

Игра быстрее запускается. Встроенный набор картинок лежит в приложении строкой base64, и при запуске
игра декодировала его целиком — 4 МБ: без JIT это 0,5–0,8 с. Теперь при запуске декодируются только
список картинок и календарь, а узор — когда картинку открывают. Эта часть запуска без JIT занимает
0,1 с. Средняя картинка открывается за миллисекунду, самая большая картина — на 30 мс дольше прежнего.

Текст UTF-8 — указатель работ, JSON набора, файл переноса — пишут и читают встроенные
`TextEncoder` и `TextDecoder`, если они есть и проходят проверку при запуске; иначе — свой код, как
раньше. Указатель работ переписывается на каждой записи работы, и за год картинок дня свой код
тратил на него без JIT 14–22 мс в секунду вышивания; встроенные — около миллисекунды.

Для замеров на телефоне перед 1.0 — памятка на один заход: что открыть, где взять число и какой
порог ([`docs/06-testing.md`](docs/06-testing.md), §6). На экране «Файл работы» появилась кнопка
«Поделиться числами», как в «Замере канвы»: все числа уходят одним сообщением.

### 0.14.2 — картинки с «да» владельца

Владелец разрешил к выпуску все картинки набора, кроме музейных — картин, чьи оригиналы хранятся
в российских музеях: для них нужна лицензия музея (решение В12). Таких 18 — 15 в «Живописи» и 3

остаются в закрытой веб-версии для проверки, и в «Листе узоров» пометка «Только для проверки» теперь
только у них.
Музыки в APK пока нет: в выпуск идёт пьеса с «да» владельца, а их ещё нет (В6).

### 0.14.1 — номер виден на любой клетке

Номер на клетке выбранной нити местами был чуть бледнее нормы: на полоске штриховки контраст
падал до 4,4 : 1 при нужных 4,5 : 1 — для тех, кто вышивает без очков, это заметно. Теперь цвет
номера выбирается по точной яркости клетки, и на любой нити, в «Крестике» и «Мозаике», с
подсветкой и без, контраст не ниже 4,5 : 1.

### 0.14.0 — к закрытому тесту

В «Сообщить об ошибке» — две новые строки: сколько раз игру открывали и сколько раз она
оборвалась, не уйдя в фон, и сколько картинок закончено. Из этих отчётов в конце закрытого теста
считаются ворота выпуска: «сессий без сбоев ≥ 99,5 %» и «≥ 200 законченных картинок». Счёт
хранится только на телефоне и уходит лишь в отчёте, который игрок видит целиком и отправляет сам.
Для тестировщиков — памятка `store/closed-test.md`: как поставить, что попробовать и как прислать
отчёт.
