# Узоры

Раскраска по номерам в виде **вышивки крестиком** — четвёртая игра студии «Горница»
([gornitsa.games](https://gornitsa.games/)) после «Вотчины», «Нард» и «Анамнеза». Картинка —
схема на канве, клетки подписаны номерами нитей; выбираете нить и вышиваете касанием или
проводя пальцем. Орнаменты по мотивам народной вышивки, русская живопись, сказочные
иллюстрации, Россия сто лет назад в цвете, цветы, природа и города. Новая картинка
каждый день, спокойная музыка, никакой спешки. Без интернета, без регистрации, без рекламы;
подписка «Узоры+» через RuStore Pay. Android, RuStore. Expo / React Native / TypeScript / Skia.

**Состояние** — версия, этап, что дальше и что ждёт владельца — в [`STATUS.md`](STATUS.md).

## Чем отличается

1. **Вышивка, а не «ещё одна раскраска».** Канва, нити с названиями, крестики; после
   последнего стежка — «Как вышивалось» и рассказ о картине. Игровая вышивка в RuStore
   почти пуста, а вышивальщицы там есть ([`docs/11-market.md`](docs/11-market.md)).
2. **Без рекламы и без ловушек.** Ни одного ролика; картинка дня бесплатно каждый день
   и навсегда; подписка без пробной недели с автосписанием, начатое дошивается и после неё.
3. **Бережно к глазам и времени.** Крупные номера, ошибиться клеткой нельзя, «Где ещё?»
   находит последние клетки, вся библиотека работает без интернета, ничего не сгорает.

## Как собрать

```bash
npm ci
bun tools/content/build.ts          # картинки → встроенный набор (без него приложение не собирается)
npx tsc --noEmit && npx tsc --noEmit -p tools && npm run lint && bun test tools/test
npm run export:web && npm run e2e   # веб-сборка и сценарий Playwright
UZORY_WEB_BASE=/uzory/test npx expo export --platform web --output-dir dist-site   # сборка для сайта
E2E_DIST=dist-site E2E_BASE=/uzory/test npm run e2e                                  # сценарий по ней
bun tools/content/sheet.ts          # лист превью картинок → dist/sheet/
FFMPEG=/путь/к/ffmpeg bun tools/audio/music.ts   # пьесы из assets/music/music.yaml → .webm
```

На каждый PR CI проверяет типы, линтер и тесты (`.github/workflows/pr.yml`); кто сливает —
по уставу ([`docs/05-process.md`](docs/05-process.md), «Ветки»). APK (AAB — нет, пока нет Google Play) CI (`android.yml`) собирает
на тег версии `vX.Y.Z` — только с картинками и пьесами с «да» владельца (`--release`) и
с постоянным ключом из секретов репозитория (там же, «Секреты»);
без ключа APK для телефона нет: файл только проверяется (размер, 16 КБ, разрешения) и не
выкладывается. Веб-сборка для сайта — раз в сутки, если `main` ушёл вперёд, и вручную
(`site.yml`): после сценария в браузере она уходит в ветку `vps`, зашифрованная ключом
сервера; сервер выкладывает её на <https://gornitsa.games/uzory/test/> под паролем
([`docs/specs/2026-09-web.md`](docs/specs/2026-09-web.md)).

## Версии

### 1.1.0 — «Светлица»

- Новое: «Светлица» — комната, где на стенах в рамах висят все ваши готовые работы, с табличкой под каждой. Стены листаются, касание работы открывает её.
- Только что вышитую работу можно сразу «Повесить на стену» — и она займёт своё место среди прежних.
- На главной — полоса стены с последними работами. Купленные рамки и стена украшают и комнату.
- «Поделиться стеной» — вся стена одной картинкой.

### 1.0.1 — первый выпуск в RuStore

- Больше трёхсот картинок: орнаменты, «Россия в цвете», цветы, природа, города, старинные схемы, живопись и картинки для детей.
- Картинка дня — каждый день новая, бесплатно и навсегда.
- «Свой узор» — схема вышивки из своего снимка; первый узор — бесплатно.
- «Узоры+» на месяц или на год — вся библиотека и новые картинки каждую неделю. Рамки и стены для готовых работ — навсегда.

### 1.0.0 — не вышла

Сборка тега `v1.0.0` остановилась на проверке разрешений: SDK оплаты RuStore принёс `RECEIVE_BOOT_COMPLETED`
(запуск после перезагрузки телефона). В 1.0.1 оно вырезано, а на экране «Узоры+» появилась ссылка «Условия».
В остальном 1.0.1 — то, что готовилось как 1.0.0.

### 0.24.3 — календарь 1.0 набран, ещё шесть листов на отбор

- Картинок дня хватает на 125 дней со дня выхода — больше 120, которых требуют ворота 1.0. Прежний счёт
  шёл по календарю закрытого теста, а при выходе календарь начинается заново.
- В закрытой веб-версии — ещё шесть ботанических листов «Цветов» на отбор: подробнее, с дорисованными
  лепестками и сплошными стеблями.
- В библиотеке игры всё как в 0.24.2.

### 0.24.2 — 24 исправленные картинки на отбор

- В закрытой веб-версии — 24 картинки, исправленные по словам владельца: кадр без лишнего, лист и кошка
  крупнее, стебель лилий без белой полосы, у селезня коричневый клюв, листы и картины подробнее, новый
  рисунок «Каймы с ягодами».
- В библиотеке игры всё как в 0.24.1: исправленные картинки придут в выпуск после «да».

### 0.24.1 — 313 картинок в выпуске, «Настроить узор» в «Листе узоров»

- В библиотеке — 313 картинок вместо 281: ещё 32 картинки получили «да» владельца 1 ноября 2026 года — цветы с
  ботанических листов и картин, снимки природы и городов, «Вид на Златоуст». Картинок дня хватает до 10 февраля
  2027 года.
- В «Листе узоров» закрытой веб-версии у картинок из снимков и картин — «Настроить узор»: сколько клеток,
  сколько нитей и упрощение. С «Да» картинка пересобирается с этими настройками и сразу идёт в выпуск, без
  второго отбора; с «Нет» или «Позже» — пересобирается так и показывается снова. Фон — словами в комментарии.

### 0.24.0 — несколько овалов главного, «Найти лица» и «Найти главное» для проверки

- «Свой узор»: овалов главного — сколько нужно, до шести. «Ещё овал» — для второго и третьего лица,
  «Убрать овал» убирает выбранный. В каждом овале — свои нити, и глаза и блики не стираются.
- «Найти лица» и «Найти главное» — в сборках для проверки. «Найти лица» сама ставит овал на каждое лицо в
  кадре, «Найти главное» — на цветок, кошку или дом: на то, что не похоже на края кадра. Всё считается на
  телефоне, снимок никуда не уходит. В 1.0 — если на снимках владельца работает в большинстве случаев.
- «О программе»: детектор лиц pico и его лицензия.
