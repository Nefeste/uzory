# Узоры

Раскраска по номерам в виде **вышивки крестиком** — четвёртая игра студии «Горница»
([gornitsa.games](https://gornitsa.games/)) после «Вотчины», «Нард» и «Анамнеза». Картинка —
схема на канве, клетки подписаны номерами нитей; выбираете нить и вышиваете касанием или
проводя пальцем. Орнаменты по мотивам народной вышивки, русская живопись, сказочные
иллюстрации, Россия сто лет назад в цвете, цветы, природа и города. Новая картинка
каждый день, спокойная музыка, никакой спешки. Без интернета, без регистрации, без рекламы;
подписка «Узоры+» через RuStore Pay. Android, RuStore. Expo / React Native / TypeScript / Skia.

**Состояние** — версия, этап, что дальше и что ждёт владельца — в [`STATUS.md`](STATUS.md).

## Чем отличается

1. **Вышивка, а не «ещё одна раскраска».** Канва, нити с названиями, крестики; после
   последнего стежка — «Как вышивалось» и рассказ о картине. Игровая вышивка в RuStore
   почти пуста, а вышивальщицы там есть ([`docs/11-market.md`](docs/11-market.md)).
2. **Без рекламы и без ловушек.** Ни одного ролика; картинка дня бесплатно каждый день
   и навсегда; подписка без пробной недели с автосписанием, начатое дошивается и после неё.
3. **Бережно к глазам и времени.** Крупные номера, ошибиться клеткой нельзя, «Где ещё?»
   находит последние клетки, вся библиотека работает без интернета, ничего не сгорает.

## Как собрать

```bash
npm ci
bun tools/content/build.ts          # картинки → встроенный набор (без него приложение не собирается)
npx tsc --noEmit && npx tsc --noEmit -p tools && npm run lint && bun test tools/test
npm run export:web && npm run e2e   # веб-сборка и сценарий Playwright
UZORY_WEB_BASE=/uzory/test npx expo export --platform web --output-dir dist-site   # сборка для сайта
E2E_DIST=dist-site E2E_BASE=/uzory/test npm run e2e                                  # сценарий по ней
bun tools/content/sheet.ts          # лист превью картинок → dist/sheet/
FFMPEG=/путь/к/ffmpeg bun tools/audio/music.ts   # пьесы из assets/music/music.yaml → .webm
```

На каждый PR CI проверяет типы, линтер и тесты (`.github/workflows/pr.yml`); PR без путей
владельца из `.github/CODEOWNERS` сливается сам после зелёных проверок и метки `ревью: ок`
от Ревьюера (`automerge.yml`), с путями владельца — его сливает владелец
([`docs/05-process.md`](docs/05-process.md), «Ветки»). APK (AAB — нет, пока нет Google Play) CI (`android.yml`) собирает
на тег версии `vX.Y.Z` — только с картинками и пьесами с «да» владельца (`--release`) и
с постоянным ключом из секретов репозитория (там же, «Секреты»);
без ключа APK для телефона нет: файл только проверяется (размер, 16 КБ, разрешения) и не
выкладывается. Веб-сборка для сайта — раз в сутки, если `main` ушёл вперёд, и вручную
(`site.yml`): после сценария в браузере она уходит в ветку `vps`, зашифрованная ключом
сервера; сервер выкладывает её на <https://gornitsa.games/uzory/test/> под паролем
([`docs/specs/2026-09-web.md`](docs/specs/2026-09-web.md)).

## Версии

### 0.14.1 — номер виден на любой клетке

Номер на клетке выбранной нити местами был чуть бледнее нормы: на полоске штриховки контраст
падал до 4,4 : 1 при нужных 4,5 : 1 — для тех, кто вышивает без очков, это заметно. Теперь цвет
номера выбирается по точной яркости клетки, и на любой нити, в «Крестике» и «Мозаике», с
подсветкой и без, контраст не ниже 4,5 : 1.

### 0.14.0 — к закрытому тесту

В «Сообщить об ошибке» — две новые строки: сколько раз игру открывали и сколько раз она
оборвалась, не уйдя в фон, и сколько картинок закончено. Из этих отчётов в конце закрытого теста
считаются ворота выпуска: «сессий без сбоев ≥ 99,5 %» и «≥ 200 законченных картинок». Счёт
хранится только на телефоне и уходит лишь в отчёте, который игрок видит целиком и отправляет сам.
Для тестировщиков — памятка `store/closed-test.md`: как поставить, что попробовать и как прислать
отчёт.

### 0.13.0 — набор недели

У игрока ничего не меняется: эта версия — для студии. Новые картинки после выхода приходят
наборами недели, и теперь их собирает и выкладывает автоматика: PR недели с новыми картинками
и файлом `content/week.yaml` сливается — набор собирается из картинок с «да», которых ещё не
было, календарь картинок дня продлевается на неделю, каталог подписывается и выкладывается на
сервер, а потом скачивается обратно и сверяется. После каждого слияния картинок проверяется,
что выпущенные узоры собираются клетка в клетку, — иначе у игроков разошлась бы начатая работа.
Первая выкладка — после ключа подписи каталога (В18) и доступа к серверу (В9).

### 0.12.0 — экран «Узоры+» без покупки

Подписка «Узоры+» — как её увидит игрок: что даёт, цены за месяц и за год, до кнопки — всё,
что требует закон (автопродление, когда следующее списание, где отменить в RuStore), «Восстановить
покупки», политика. Права подписки хранятся и действуют без сети до конца оплаченного срока.
Покупки ещё нет — RuStore Pay подключается после ИП (В2), — поэтому в сборке для проверки экран —
образец в «Для проверки»: цены — гипотезы, кнопка неактивна, а переключатель «Как в 1.0» запирает
картинки «Узоры+», как у игрока без подписки: вместо «Вышивать» — «Подробнее».

### 0.11.0 — картинки дня по временам года

Календарь картинок дня во встроенном наборе следует году: у картинки может быть время года
(`season`) — снеговик встаёт только зимой, арбуз — летом, и не в первые дни сезона, а
вразбивку по нему, — или праздник (`day`): ёлочка — в канун Нового года, тюльпан — 8 Марта.
Коллекции идут вперемешку до конца календаря, а не одна за другой, и две картинки одной
коллекции подряд не встают, пока есть из чего выбрать.

### 0.10.3 — библиотека не держит экран

Превью в библиотеке и коллекциях считаются по одному, и между ними экран отвечает на касания.
Раньше на недорогом телефоне библиотека с большими картинами несколько секунд не отзывалась
даже на «назад», пока не досчитает все превью. Сразу считаются ряды первого экрана, остальные —
при прокрутке.

### 0.10.2 — отбор по коллекциям

В «Листе узоров» над картинками — коллекции с числом картинок: «Цветы · 27», «Орнаменты · 58»
и другие. Отбирать двести картинок можно по частям, коллекцию за коллекцией; «Без отметки»
работает и внутри коллекции, а «Скопировать решения» по-прежнему даёт все отметки сразу.

### 0.10.1 — «Лист узоров» открывается сразу

В листе для отбора почти двести картинок, и при открытии он разбирал все узоры и рисовал
все превью разом: на компьютере — две секунды, на недорогом телефоне — десятки. Теперь
превью и числа карточки считаются, когда карточка показывается, и лист открывается за доли
секунды.

### 0.10.0 — музыка

На экране вышивания — спокойная музыка: пять пьес по кругу в случайном порядке — ноктюрн
Бородина, «Песнь менестреля» Глазунова, ноктюрн Шопена, ария Баха и «Утро» Грига. Начинается
с первого стежка, тихо, и за пять секунд нарастает; ушли с экрана — затихает, вернулись и
сделали стежок — продолжается с того же места. Выключается в меню ⋮ и в настройках, в
беззвучном режиме телефона молчит. Записи — только отданные исполнителями в общественное
достояние или CC0, у каждой в «О программе» — исполнитель и лицензия. Какие пьесы останутся,
решает владелец: в выпуск идут только пьесы с его «да».

### 0.9.2 — узор открывается целым

Небольшая картинка в широком окне могла открыться обрезанной сверху и снизу: канва считала
масштаб до того, как под ней появлялась полоса нитей. Теперь, пока канву не двигали, при смене
её размера узор открывается заново — целиком.

### 0.9.1 — «Готово» на небольшом телефоне

На узком экране кнопки «Как вышивалось» и «Поделиться» встают одна под другой, а не обрезают
подписи, большая картина на «Готово» видна в рамке целиком, а «О картине» открывается во весь
экран. Снимки для RuStore и сайта пересняты с новым «Готово».

### 0.9.0 — отбор картинок для владельца

В сборках для проверки «Лист узоров» стал инструментом отбора: у каждой картинки — «Да», «Нет»
или «Позже», вверху — сколько отмечено и фильтр «Без отметки», а «Скопировать решения» собирает
отметки в текст для ассистента. Игроки этого не видят: «Лист» есть только в сборках 0.x.

### 0.8.0 — счётчики без слежки

Чтобы понимать, возвращаются ли люди вышивать, игра раз в день вместе с вопросом о новых картинках
сообщает несколько обезличенных чисел: версию, откуда она установлена, неделю установки, сколько
дней прошло и сколько картинок и минут вышивали в прошлый день игры — промежутками. Ни номера
установки, ни рекламного идентификатора, ни модели телефона: связать эти числа с человеком нельзя.
На сервере они складываются в суммы по дням, а сырой журнал живёт не дольше недели.

### 0.7.0 — новые картинки по сети

Игра научилась получать новые картинки без обновления из магазина. Раз в день, пока она открыта,
она заглядывает на сайт студии: если там вышел набор новых картинок, он скачивается и появляется
в библиотеке с меткой «Новое». Всё, что приходит по сети, подписано студией и проверяется до
того, как попасть в игру, — чужие картинки в неё не подсунуть. Без интернета игра работает как
прежде и ни о чём не жалуется. Сами наборы на сайте начнут выходить, когда будет готов сервер.

### 0.6.0 — перенос работ файлом

В настройках появился раздел «Перенос». «Сохранить работы в файл» собирает все работы — начатые,
готовые и свои узоры — в один файл и отдаёт его в «Поделиться»: в мессенджер себе, на почту,
в облако. «Загрузить из файла» на другом телефоне добавляет эти работы к тем, что там уже есть:
если работа есть и тут и там, остаётся та, где вышито больше. В веб-версии файл скачивается
и выбирается с диска — можно начать картину на компьютере и дошить её на телефоне.

### 0.5.0 — «Готово»: рамка, «О картине», «Поделиться», «Дальше»

Готовая работа встаёт в деревянную рамку. «О картине» — кто и когда её написал или снял, где она
хранится и откуда взята, и подпись: «Сергей Прокудин-Горский. Крестьянские девушки, 1909. Схема для
вышивки по мотивам снимка» — то же на карточке картинки и в меню канвы. «Поделиться» делает картинку
вашей работы в рамке с названием и автором и отдаёт её в «Поделиться» телефона — в мессенджер,
в галерею, родным; в веб-версии картинка скачивается файлом. «Дальше» ведёт к сегодняшней картинке
дня, если она ещё не вышита, а если вышита — к следующей картинке той же коллекции.

### 0.4.0 — библиотека, мои работы и календарь

С главной теперь открываются библиотека, «Мои работы» и календарь. В библиотеке — коллекции рядами:
орнаменты, живопись, сказки, Россия в цвете, цветы, природа, города; «Все» открывает коллекцию
целиком, с отбором по размеру и «Скрыть готовые». Касание превью — карточка картинки: размер,
число нитей и примерное время (у больших картин — в часах), «О картине» и кнопка «Вышивать»,
«Продолжить» или «Вышить ещё раз». В «Моих работах» — начатые и готовые; долгое касание удаляет
работу, спросив. В календаре — картинки дня по месяцам, начиная с первого запуска: пропущенный
день можно вышить когда угодно. Метка «Узоры+» показывает, какие картинки войдут в подписку, но в
сборке для проверки открыто всё.

### 0.3.0 — мини-карта и звуки

Когда большая картина не помещается на экран, в правом верхнем углу канвы появляется мини-карта:
вся картинка маленькой — вышитое цветом, остальное бледно — и рамка там, где вы сейчас. Коснитесь
мини-карты или проведите по ней пальцем — канва переедет туда. Появились звуки: мягкий шорох стежка,
тихий звон, когда нить закончена, и короткий перезвон готовой картинки; они не заглушают вашу
музыку, в беззвучном режиме телефона молчат и выключаются в настройках. Законченная нить секунду
стоит с ✓ на своём месте и только потом уезжает в конец полосы.

### 0.2.0 — главная, настройки и подсказки

Главная стала игровой: при первом запуске на ней первая картинка, а когда она вышита — картинка
дня, каждый день новая. Под ней — «Продолжить» с последней начатой работой. «Библиотека», «Мои
работы» и «Календарь» уже на месте и появятся в следующих сборках. В первой картинке появились
подсказки: одна строка внизу канвы — как вышивать касанием, кистью, как приблизить и как найти
последние клетки; каждая уходит, как только вы это сделали. В меню ⋮ на канве — «О картине»,
стиль «Крестик» или «Мозаика» и настройки. В настройках — стиль, крупные номера, подсветка нити,
заливка, следующая нить сама, подсказки, вибрация, «Сообщить об ошибке», политика и «О программе»
с источником каждой картинки. Если игра не открылась, на экране сбоя есть «Начать заново»: настройки
вернутся к исходным, работы останутся. Проверки для владельца — «Лист узоров», «Свой узор»,
«Замер», «Файл работы» — внизу главной, в разделе «Для проверки».

### 0.1.0 — свой узор и старинные схемы

В веб-версии появился «Свой узор»: выберите снимок, рамкой — кадр (колёсико — ближе и
дальше), размер и число нитей — кнопками. Рядом сразу узор, «сколько на сколько», нитей и
минут, и приговор: подходит ли он для вышивки и что поправить. «Упрощение» — нет, немного
или сильно — выравнивает цвет внутри пятен: листва и трава не рассыпаются на одиночные
клетки, вышивать проще. Снимок остаётся в браузере
и никуда не уходит; узоры — в «Моих узорах». Для владельца — «Карточка для библиотеки»:
карточка с кадром и снимок без метаданных для «Природы» и «Городов». В «Листе» — пробные
узоры: фрагменты картин — главное с той же плотностью, от 35 минут до 3 часов, и старинные
схемы для вышивки — берлинские листы 1850–1874 годов и каймы из «Живописного обозрения»
1890 года, от 5 минут до часа с четвертью.

### 0.0.5 — вышивать с компьютера

Появилась веб-версия для проверки с компьютера — gornitsa.games/uzory/test/, только для
владельца и по паролю. Колёсико мыши приближает к тому месту, где курсор, правая кнопка
двигает канву, клавиши «+», «−» и «0» меняют масштаб; щелчок — стежок, протянуть — кисть,
двойной щелчок — заливка. В «Листе» начатая картинка открывается с того же места —
большие картины вышиваются не за один вечер; на широком экране «Лист» — сеткой. Работы
в браузере хранятся в самом браузере.

### 0.0.4 — картины в четыре крестика на сантиметр

Картины собираются по размеру холста — четыре клетки на сантиметр, как стразы в алмазной
мозаике: «Утро в сосновом лесу» — 852 × 577 клеток, и видно каждого медвежонка. Большие
холсты — работа на много вечеров. В библиотеке появились семь снимков из Кирова: лилии,
рододендрон, селезень, белка у кормушки, ледоход, набережная Вятки, зонтики в парке Аполло.
«Замер канвы» и «Файл работы» проверяют узор 852 × 556.

### 0.0.3 — огромные картины

Появился размер «Огромная» — до 200 клеток по стороне и 45 нитей. Картины с фигурами

### 0.0.2 — картины ярче, замер больших узоров

Картины и снимки собираются с бо́льшим числом нитей: у картин теперь 15–29 нитей вместо
9–16, и вернулись пропавшие оттенки — голубая дымка и золотой свет в лесу, цвет лица,
рыжие дыни. «Лунная ночь на Днепре» убрана: узор выходил сплошь чёрным. В «Замере канвы» —
новый узор 250 × 250 · 45, предел для больших картин.

### 0.0.1 — прототипы

Внутренняя сборка для владельца, ещё не игра: главная с первой картинкой и три проверки.
«Лист узоров» — все картинки встроенного набора так, как их увидит игрок. «Замер канвы» —
узор 120 × 120 или 150 × 200: канва сама двигается, приближается и водит кистью, а экран
показывает время кадров. «Файл работы» — большая работа кистью до конца: размер файла,
запись и повтор «Как вышивалось». Первую картинку можно вышить целиком: касание, кисть,
«Где ещё?», двойное касание — заливка, долгое — выбрать нить клетки.
