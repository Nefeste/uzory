# Узоры

Раскраска по номерам в виде **вышивки крестиком** — четвёртая игра студии «Горница»
([gornitsa.games](https://gornitsa.games/)) после «Вотчины», «Нард» и «Анамнеза». Картинка —
схема на канве, клетки подписаны номерами нитей; выбираете нить и вышиваете касанием или
проводя пальцем. Орнаменты по мотивам народной вышивки, русская живопись, сказочные
иллюстрации, Россия сто лет назад в цвете, цветы, природа и города. Новая картинка
каждый день, спокойная музыка, никакой спешки. Без интернета, без регистрации, без рекламы;
подписка «Узоры+» через RuStore Pay. Android, RuStore. Expo / React Native / TypeScript / Skia.

**Состояние:** этап 0 — прототипы 0.0.1 ([`docs/specs/2026-09-spikes.md`](docs/specs/2026-09-spikes.md)):
канва на Skia одним шейдером, узоры из картин и орнаменты, файл работы и повтор, сборка APK
в CI; папка [`store/`](store/) — материалы карточки RuStore для предзаказа и для сайта студии.
У владельца — ключ подписи, название, снимки, музыка, опорный телефон, RuStore Pay на ИП
([`docs/07-roadmap.md`](docs/07-roadmap.md)).

## Чем отличается

1. **Вышивка, а не «ещё одна раскраска».** Канва, нити с названиями, крестики; после
   последнего стежка — «Как вышивалось» и рассказ о картине. Игровая вышивка в RuStore
   почти пуста, а вышивальщицы там есть ([`docs/11-market.md`](docs/11-market.md)).
2. **Без рекламы и без ловушек.** Ни одного ролика; картинка дня бесплатно каждый день
   и навсегда; подписка без пробной недели с автосписанием, начатое дошивается и после неё.
3. **Бережно к глазам и времени.** Крупные номера, ошибиться клеткой нельзя, «Где ещё?»
   находит последние клетки, вся библиотека работает без интернета, ничего не сгорает.

## Как собрать

```bash
npm ci
bun tools/content/build.ts          # картинки → встроенный набор (без него приложение не собирается)
npx tsc --noEmit && npx tsc --noEmit -p tools && npm run lint && bun test tools/test
npm run export:web && npm run e2e   # веб-сборка и сценарий Playwright
bun tools/content/sheet.ts          # лист превью картинок → dist/sheet/
```

APK собирает CI (`.github/workflows/android.yml`) — с постоянным ключом из секретов
репозитория ([`docs/05-process.md`](docs/05-process.md), «Секреты»); без ключа APK для телефона нет.
Проверочная сборка без ключа — по «[apk]» в сообщении коммита: файл собирается и проверяется
(размер, 16 КБ, разрешения), но не выкладывается.

## Версии

### 0.0.1 — прототипы

Внутренняя сборка для владельца, ещё не игра: главная с первой картинкой и три проверки.
«Лист узоров» — все картинки встроенного набора так, как их увидит игрок. «Замер канвы» —
узор 120 × 120 или 150 × 200: канва сама двигается, приближается и водит кистью, а экран
показывает время кадров. «Файл работы» — большая работа кистью до конца: размер файла,
запись и повтор «Как вышивалось». Первую картинку можно вышить целиком: касание, кисть,
«Где ещё?», двойное касание — заливка, долгое — выбрать нить клетки.
